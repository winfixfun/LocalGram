# LocalGram# LocalGram2

Локальный HTTPS-мессенджер для небольшой компании друзей. Работает в Termux, Windows и Linux с одним и тем же Python-кодом.

## Требования

- Python 3.10 или новее
- pip
- устройства в одной Wi-Fi сети или подключены к одной точке доступа

## Запуск

```bash
python -m pip install -r requirements.txt
python app.py
```

При первом запуске будут созданы `instance/localgram.db`, секрет сессий и самоподписанный сертификат. Сервер напечатает локальные HTTPS-адреса. На другом устройстве откройте адрес с LAN-IP хоста, например `https://192.168.x.x:8443`.

Предупреждение браузера о самоподписанном сертификате ожидаемо. Выберите переход на сайт вручную. Не публикуйте порт в интернет: приложение рассчитано на доверенную локальную сеть.

### Termux

```bash
pkg install python
cd /путь/к/LocalGram2
python -m pip install -r requirements.txt
python app.py
```

Android может выгружать Termux в фоне; на время общения не закрывайте сессию и при необходимости отключите оптимизацию батареи для Termux.

## Настройки окружения

- `LOCALGRAM_HOST` — интерфейс, по умолчанию `0.0.0.0`
- `LOCALGRAM_PORT` — порт, по умолчанию `8443`
- `LOCALGRAM_MAX_FILE_MB` — лимит файла, по умолчанию `25`, максимум приложения 100
- `LOCALGRAM_TESTING=1` — использовать отдельную тестовую БД/instance при smoke-тесте

Пример:

```bash
LOCALGRAM_PORT=9443 python app.py
```

PowerShell:

```powershell
$env:LOCALGRAM_PORT="9443"
python app.py
```

## Резервное копирование

Остановите сервер и скопируйте папку `instance`. В ней находятся БД, файлы внутри БД, ключ сессий и HTTPS-сертификат.

## Проверка

В одном окне запустите тестовый сервер:

```bash
LOCALGRAM_TESTING=1 LOCALGRAM_PORT=9443 python app.py
```

В другом:

```bash
python tests/smoke_test.py https://127.0.0.1:9443
```

Тест создаёт двух случайных пользователей, проверяет автоматически созданный чат, выполняет вход, отправляет текст и файл и скачивает файл обратно. Дополнительные тесты проверяют настройки профиля, лимит username, пароль и удаление аккаунта.

## LocalGram2

- Шестерёнка в шапке открывает настройки профиля и аккаунта.
- Все зарегистрированные пользователи автоматически получают личные чаты друг с другом.
- Username можно менять не более 10 раз за календарные сутки серверного времени; лимит сбрасывается в полночь.
- Для смены пароля и удаления аккаунта сервер обязательно проверяет текущий пароль.
- При запуске существующая база данных автоматически дополняется новой схемой и недостающими личными чатами.
